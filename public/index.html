Chat

Follow-ups stay in this thread. Pick a Together model, then ask a question. Enter sends; Shift+Enter adds a line.

How this works

TypeScript Express on Render. This page lists Together text models and sends the thread to POST /ui/chat. API clients use bearer CHAT_API_KEY on single-turn POST /chat, which always uses TOGETHER_MODEL. 

curl -X POST "$SERVICE_URL/chat" \
  -H "Authorization: Bearer $CHAT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"message":"Hello"}'
